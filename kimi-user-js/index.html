GeKeCy-Kimi资料设置脚本

修改 Kimi 昵称、简介与头像

脚本说明

运行在浏览器的**油猴脚本**。在浏览器打开 kimi.com 并登录，安装并启用脚本后在 kimi.com 页面右下角会出现可拖拽按钮，点按该按钮后将展开一个面板，用于修改昵称、简介与头像， 绕过前端 昵称简介 长度限制，并支持上传动态头像。

  • 昵称、简介超长输入，不受前端字符上限约束，与「昵称超长」「简介超长」说拜拜
  • 头像上传，支持 GIF 动态头像
  • 内置「检测登录状态」，在日志区可读出当前 Kimi 账号的昵称、简介与**头像链接**
  • 脚本面板可拖拽、可折叠；日志支持复制与清空
  • **脚本开源**：本脚本全量开源，脚本所做全部可查
  • **脚本原理**：脚本本质上是模拟了 Kimi App 的上传请求，用浏览器原生接口实现，绕过了前端对 昵称与简介的长度限制 和 头像上传的 GIF 文件限制。
安装

Android

VIA 浏览器 → 设置 → 脚本 → 右上角 + → 新建 → 粘贴代码 → 保存。
其他可选：Kiwi + Tampermonkey、Edge + Tampermonkey、Firefox + Violentmonkey。

iOS

App Store 安装 Stay 或 Userscripts → 设置 → Safari → 扩展 → 启用 → 新建脚本 → 粘贴代码 → 保存。

桌面端

Chrome / Edge / Firefox 安装 Tampermonkey 或 Violentmonkey → 创建新脚本 → 粘贴代码 → 保存。也可直接下载下方 .user.js 文件，脚本管理器会自动识别。

    使用
    
    
      
  1. 在浏览器中打开 kimi.com，登录账号
    2. 
      
  2. 安装并启用脚本，刷新页面，右下角出现黑色「修改 Kimi 资料」按钮
    3. 
      
  3. 点击按钮展开脚本面板，填写昵称或简介后点对应的修改按钮；修改头像则点「修改头像」选择文件
    4. 
      
  4. 日志区会逐条输出包涵 成功/失败的提示 的日志，可根据提示适当调整
    5. 
      
  5. 遇到问题可「复制日志」，将这些日志反馈给我们
    6. 
      
  6. **感谢您的使用**
    7. 
    

  


  
  

    注意
    
    
      
  • 头像和名字 30 天内合计最多修改 10 次，这是服务端限制，客户端脚本无法绕过
    • 
      
  • 返回 401 / 403 表示未登录或 Token 失效，重新登录后再试
    • 
      
  • 头像上传返回 413 表示文件过大，压缩后重试
    • 
      
  • 脚本只在 kimi.com 及其子域触发，其他网页不会出现脚本按钮
    •
